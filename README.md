`VECTRON.sol` in this repository is the exact deployed source. Verify it yourself: running `sha256sum VECTRON.sol` must print `dbe9eea02406f3bff8c14286790d8180a4cbfafed985a9d667dfe7ead25c7d94`. The file has no trailing newline, which is why the hash only matches the original byte for byte.

Two earlier deployments are superseded and inert; see the [Mainnet Launch Record](VECTRON_Mainnet_Launch_Record.md). The address above is the only official contract.
